📅 Planning des premiers jours (semaine, vue horaire)

💡 Clic dans une case vide = créer un créneau à cette heure (pas de 30 min) · Clic sur un bloc = modifier / supprimer · Glisser un bloc = le déplacer (heure ou jour) · Tirer la poignée striée en bas d'un bloc = étirer / réduire sa durée.

⚙️ Modèle type – propositions standard

Les tâches type alimentent la checklist des prérequis ; les créneaux type alimentent le planning. Ils sont repris à chaque création d'arrivant (case « Charger les propositions type »). Décalage (j) = jours par rapport à J0 (date d'arrivée) : -5 = J‑5, 0 = jour J, 1 = lendemain. Modifiez les lignes puis 💾.
⚠️ Les arrivants déjà créés conservent leurs données : utilisez « 🔄 Regénérer depuis le modèle » sur leur fiche pour les réaligner.
